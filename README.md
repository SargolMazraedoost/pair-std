# pair-std

A collaborative repository for exploring pair programming patterns, collaborative git workflows, and shared development standards.

## Objectives

- Practice pair programming and co-authored commit standards.
- Maintain clean, reproducible branch and merge strategies.
- Demonstrate GitHub collaboration practices.
